# gather_files.py

A simple, configurable Python script that recursively scans a directory, selects files based on whitelist rules, and combines them into a single output file.

---

## 📌 Overview

`gather_files.py` is designed to help you quickly bundle source files (e.g., `.py`, `.js`, `.html`, `.css`) into one consolidated file. This is useful for:

* Code reviews
* Sharing projects as a single file
* Feeding code into LLMs or analysis tools
* Archiving relevant source files

---

## ⚙️ How It Works

The script walks through a directory tree and selects files based on:

* **Whitelisted file extensions**
* **Explicitly whitelisted file paths**

It then concatenates all matched files into a single output file, clearly separating each file with headers.

---

## 🧩 Configuration

Edit these variables at the top of the script:

### `DEFAULT_SKIP_DIRS`

Directories ignored during scanning.

```python
DEFAULT_SKIP_DIRS = {"__pycache__", "venv", ".git", ...}
```

---

### `WHITELIST_EXTENSIONS`

File types to include.

```python
WHITELIST_EXTENSIONS = {".py", ".js", ".css", ".html"}
```

* Accepts extensions with or without a leading dot
* Case-insensitive

---

### `WHITELIST_PATHS`

Specific files to include regardless of extension.

```python
WHITELIST_PATHS = {"src/index.html", "scripts/app.js"}
```

---

## ✅ Inclusion Rules

A file is included if:

* Its extension matches `WHITELIST_EXTENSIONS`, **OR**
* Its relative path matches `WHITELIST_PATHS`

If both are empty → **no files will be selected**

---

## 🚫 Exclusion Options

### Exclude Files by Name

```bash
--exclude-files exclude.txt
```

Where `exclude.txt` contains:

```
file1.py
secret.js
```

---

### Exclude Additional Directories

```bash
--exclude-dirs node_modules,coverage,tmp
```

---

## ▶️ Usage

### Basic

```bash
python gather_files.py
```

* Scans current directory
* Outputs to `combined.txt`

---

### Custom Input & Output

```bash
python gather_files.py ./my_project output.txt
```

---

### Full Example

```bash
python gather_files.py ./src combined.txt \
  --exclude-files exclude.txt \
  --exclude-dirs node_modules,build
```

---

## 📄 Output Format

The combined file will look like:

```text
# combined file
# Generated by gather_files.py

# ========================
# FILE: path/to/file.py
# ========================

<file contents here>
```

Each file is clearly separated and labeled.

---

## ⚠️ Notes

* The script skips itself automatically
* Hidden directories (starting with `.`) are ignored
* Files are read using UTF-8 with fallback for errors
* Output is overwritten if it already exists

---

## 🛠️ Requirements

* Python 3.x
* No external dependencies

---

## 💡 Tips

* Use narrow extension filters to avoid huge outputs
* Combine with `.gitignore`-style exclude lists for cleaner results
* Great for preparing code for AI analysis or documentation
